# Kenny Perez, MD | AI systems and evaluation

I’m a psychiatrist and Chief Medical Officer at Elevate Psychiatry in South Florida. I build software for problems I know firsthand, often with Claude Code as my coding partner. My work spans bilingual voice agents, recruiting, and quantitative research. I design the workflows, decide what counts as a correct outcome, and investigate the cases where the software falls short.
